Install DraftMate on your phone

The phone must be on the same Wi-Fi, and DraftMate must be running on the computer.

Android · one tap

Download the DraftMate app
  1. Open the downloaded DraftMate.apk.
  2. If Android asks, allow your browser to install unknown apps, then tap Install.
No certificate setup is needed: the app already trusts this computer. If Play Protect warns about an unrecognised developer, choose Install anyway; the app was built on this computer.

iPhone, or without the app

Step 1 · Trust the certificate

Download certificate

Android:

  1. Open Settings › Security & privacy › More security settings › Encryption & credentials (names vary by phone; search Settings for "certificate").
  2. Tap Install a certificate › CA certificate, confirm, and pick DraftMate-local-CA.crt from Downloads.

iPhone:

  1. Open the downloaded file in Safari and allow the profile download.
  2. Settings › General › VPN & Device Management › DraftMate profile › Install.
  3. Settings › General › About › Certificate Trust Settings › turn on DraftMate local network CA.
This certificate can only vouch for local network addresses (192.168.x.x, 10.x.x.x, 172.16–31.x.x) and localhost, never for public websites. Remove it any time from the same settings.

Step 2 · Add to home screen

Close and reopen this page (the address bar should now show a normal lock), then:

  1. Android (Chrome): menu ⋮ › Install app (or Add to Home screen › Install).
  2. iPhone (Safari): Share › Add to Home Screen.

DraftMate now opens from its own icon, full screen, without the browser.
